## Cómo ejecutarlo

1. Descarga el proyecto desde Code → Download ZIP.
2. Descomprime todos los archivos en una misma carpeta.
3. Abre esa carpeta en Visual Studio Code.
4. En la terminal, ejecuta:

   python menu.py

Requiere Python 3. SQLite ya viene incluido con Python.
La base de datos contiene productos de práctica.

## Funciones

- Consultar productos.
- Agregar productos.
- Descontar existencias al vender.
- Comprobar que haya suficientes unidades.

## Lo que aprendí

Variables, condiciones, bucles, manejo básico de errores
y consultas SQL con SQLite.

Proyecto desarrollado paso a paso con ayuda de IA.
